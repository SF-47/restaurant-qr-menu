# Template Setup Checklist

Use this checklist when creating a QR menu site for a new restaurant client.

- [ ] Choose restaurant name in English and Arabic.
- [ ] Prepare logo and safe public promo images.
- [ ] Choose brand colors.
- [ ] Collect menu items.
- [ ] Collect Arabic and English item names.
- [ ] Collect item descriptions, if needed.
- [ ] Collect prices and confirm currency label.
- [ ] Collect WhatsApp order number.
- [ ] Collect Instagram link.
- [ ] Collect Google Maps link.
- [ ] Collect opening days and hours in English and Arabic.
- [ ] Create Firebase project.
- [ ] Enable Firestore.
- [ ] Enable Firebase Auth Email/Password sign-in.
- [ ] Create admin user.
- [ ] Create Firestore `admins/{uid}` document for the admin user.
- [ ] Update `frontend/.env` from `frontend/.env.example`.
- [ ] Update `frontend/src/config/restaurantConfig.js`.
- [ ] Add menu items through the admin panel or seed script.
- [ ] Run lint and build checks.
- [ ] Deploy Firebase Hosting.
- [ ] Connect custom domain.
- [ ] Generate QR code for the public menu URL.
- [ ] Test QR menu on phone.
- [ ] Test WhatsApp order.
- [ ] Test admin login.
- [ ] Give client admin instructions.
